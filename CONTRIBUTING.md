# Contributing

Thanks for your interest in contributing! A few quick guidelines to get started:

1. Report issues
   - Open an issue with a clear title, steps to reproduce (if applicable), and environment details (browser, Node version, etc.).
2. Propose changes
   - Fork the repo, create a branch named `fix/short-description` or `feat/short-description`.
   - Make small, focused commits with clear messages.
   - Open a pull request describing what you changed and why.
3. Code style & tests
   - Follow the existing code style (run linters/formatters if present).
   - Add tests for bug fixes or new features where appropriate.
4. Review process
   - PRs will be reviewed and may request changes; please respond to review comments.
5. License
   - By contributing, you agree your contributions will be licensed under the project’s license.

If you want a more detailed contributing guide (issue templates, PR template, CI checklist), I can create those too.
